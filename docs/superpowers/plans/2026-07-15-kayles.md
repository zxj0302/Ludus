# Kayles Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Hub game #13 `kayles` — single-row bowling pins, Sprague–Grundy (OEIS A002186), bilingual education, Hub wiring.

**Architecture:** Self-contained plugin under `packages/games/src/kayles/` mirroring `grundys-game`. State is `alive: boolean[]`; solver memoizes `g(n)` for chain length, XOR over runs; UI is click-to-confirm knock 1 or 2 adjacent pins.

**Tech Stack:** TypeScript, Vitest, React + Framer Motion, existing GamePlugin / entrySetup patterns.

## Global Constraints

- id: `kayles`; Hub `n ≤ 12`; single-chain opening
- Victory: Nim-isomorphic (`isPlayerVictory` ⟺ terminal && `currentPlayer === 1`)
- Hint on P: empty `moves` → `noWinningMove`
- Viz: live recompute from `alive` (not stale opening trace)
- Export prefixed names (`findKaylesWinningMove`, …) to avoid barrel clashes
- i18n: no hardcoded user strings; education L2/L3 × zh-CN/en
- Do not commit until user asks; do not mix thief-siege docs
