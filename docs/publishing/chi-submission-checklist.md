## Required artifacts

- [ ] Paper ≤ 6 pages ACM single-column (excl. references), **non-anonymized**
- [ ] Walkthrough video ≤ 5 min (aim ≤ 3 min), accessible encoding
- [ ] Promo still ≥ 1500×1200 + caption
- [ ] Floor plan (~2×2 m) + crowd / power / network notes
- [ ] Total upload size within CFP limit (often 250 MB)

## Demo build

- [ ] `/demo` playlist completes offline
- [ ] Default locale English
- [ ] Three acts stable (no random levels)
- [ ] Touch-friendly controls verified on target laptop/tablet

## Paper outline (suggested)

1. Introduction & contribution  
2. Related work (edu games, algo viz, progressive disclosure)  
3. System design (L1–L3, plugin architecture, demo playlist)  
4. Demonstration walkthrough (three acts)  
5. Preliminary observations / hallway study  
6. Limitations & future work
