## 1. 五段式教学统一模板

每个游戏的教学内容均按以下 Markdown 模板编写，按 `语言 × 深度` 生成 4 个文件：

```
packages/education/src/content/&lt;game-id&gt;/
├── l2.zh-CN.md    # L2 中文
├── l2.en.md       # L2 English
├── l3.zh-CN.md    # L3 中文
└── l3.en.md       # L3 English
```

### 模板结构（含 frontmatter）

````
---
````

## 2. 教学内容创作指南

### 2.1 L2 vs L3 深度差异标准

| 维度                 | L2（玩中学）                                                   | L3（专业学习）                                               |
| -------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| **目标读者**   | 有好奇心的一般玩家，无 CS 背景假设                             | CS/数学专业学生，熟悉基本算法与数据结构                      |
| **公式密度**   | 至多 1–2 个核心公式，优先用文字+图示解释                      | 可含完整推导、定理陈述与证明概要                             |
| **伪代码**     | 不出现                                                         | 提供关键算法的伪代码或指向源码                               |
| **求解器说明** | 「怎么做」——算法直观思路（如"逐行消去变量，类似加减消元法"） | 「为什么这样做」——正确性论证、复杂度推导、与其他算法的比较 |
| **生成器说明** | 告知"关卡是计算机生成并验证可解的"                             | 详细解释生成策略（反向求解、挖空+验证唯一解、难度量化公式）  |
| **篇幅**       | 每节 1–3 段，总计约 300–800 字                               | 每节可多段，总计约 1000–3000 字                             |
| **LaTeX**      | 仅行内公式（`$...$`）                                        | 行内 + 块公式（`$$...$$`）+ 矩阵/表格                      |

### 2.2 LaTeX 公式书写规范

- **行内公式**：`$x_i \in \{0, 1\}$`
- **块公式**：`$$Ax = b \pmod{2}$$`
- **矩阵**：

  $$
  \begin{pmatrix}
  1 & 1 & 0 \\
  1 & 1 & 1 \\
  0 & 1 & 1
  \end{pmatrix}
  $$
- **集合**：`$\mathbb{F}_2$`、`$\{0, 1\}^{n^2}$`
- **复杂度**：`$O(n^3)$`、`$\mathcal{O}(n^3)$`
- **保持一致**：同一概念全文件使用相同符号，不混用 `x` 与 `\mathbf{x}`

### 2.3 中英翻译规范

| 原则                    | 说明                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **公式语言无关**  | LaTeX 公式在 zh-CN 和 en 文件中完全相同，不翻译数学符号                                                                                     |
| **术语首次出现**  | 中文首次出现时附英文原文：`GF(2)（二元有限域）`；英文文件反之亦可                                                                         |
| **口语化程度**    | 中文可用"我们"拉近距离；英文保持中性学术语气（avoid "let's"）                                                                               |
| **i18n key 引用** | 文件中的 UI 术语引用 i18n key 而非硬编码：`{ { ui.solve } }` → 由 ContentRenderer 替换（空格仅文档中为防模板引擎误解析，实际使用无空格） |
| **代码关键字**    | 伪代码中的关键字保留英文（`if`, `for`, `while`），注释按语言翻译                                                                      |

### 2.4 可访问性要求

- 所有图片/图示需配 `alt` 文本（zh-CN 文件用中文描述，en 文件用英文描述）
- 颜色不作为传达信息的唯一手段（色盲友好）
- LaTeX 公式需通过 KaTeX 渲染（非图片），支持屏幕阅读器

## 4. 渐进式揭示实现

> **2026-07 更新**：原计划的 `ContentRenderer` 组件接口已被实际实现替代。教学内容现在通过 `EducationPanel`（`apps/web/src/components/EducationPanel.tsx`）渲染，使用 `MarkdownRenderer`（`@ludus/ui`）解析 .md 文件，按五段式卡片（玩/思考/揭示/求解/出题）组织，支持 L2/L3 切换、中英双语、求解器可视化嵌入和最优解步骤展示。

### 当前实现路径

| 组件 | 位置 | 职责 |
|------|------|------|
| `EducationPanel` | `apps/web/src/components/EducationPanel.tsx` | 侧边栏：五段卡片 + 实时分析 + 可视化 + 最优解 |
| `MarkdownRenderer` | `packages/ui/src/MarkdownRenderer.tsx` | KaTeX + Markdown → HTML 渲染 |
| `SectionCard` | `EducationPanel.tsx` 内 | 单段落彩色卡片（左侧色条 + 图标） |
| `KnowledgeCard` | `apps/web/src/components/KnowledgeCard.tsx` | 知识卡（状态 / 最优解 / P-position） |
| `StatusCard` | `apps/web/src/statusCards.tsx` | 游戏状态卡片（按 gameId 渲染统计数据） |

### 行为规范

| 层级   | 可见内容                                                                          | 入口           |
| ------ | --------------------------------------------------------------------------------- | -------------- |
| **L1** | 仅游戏本体，零教学内容                                                            | 无（默认状态） |
| **L2** | 侧边栏 → 实时分析卡片 + 五段教学卡片（摘要版）                                   | 点击"原理"     |
| **L3** | 侧边栏 → 完整内容（含推导过程、伪代码、出题原理）                                 | 切换 L2→L3     |

### 渲染规则

1. **L2 卡片**：紧凑布局，至多一屏；求解器演示自动播放（可暂停）。
2. **L3 文档**：类教材排版；伪代码语法高亮；公式 KaTeX 渲染。
3. **关闭行为**：L2/L3 层可随时关闭回到 L1 游戏，不丢失游戏状态。
4. **语言切换**：根据 `useGameStore.language` 加载对应语言的教学内容。
