├── l2.en.md       # L2 English
├── l3.zh-CN.md    # L3 中文

## 2. 教学内容创作指南

### 2.1 L2 vs L3 深度差异标准

| 维度                 | L2（玩中学）                                                   | L3（专业学习）                                               |
| -------------------- | -------------------------------------------------------------- | ------------------------------------------------------------ |
| **目标读者**   | 有好奇心的一般玩家，无 CS 背景假设                             | CS/数学专业学生，熟悉基本算法与数据结构                      |
| **公式密度**   | 至多 1–2 个核心公式，优先用文字+图示解释                      | 可含完整推导、定理陈述与证明概要                             |
| **伪代码**     | 不出现                                                         | 提供关键算法的伪代码或指向源码                               |
| **求解器说明** | 「怎么做」——算法直观思路（如"逐行消去变量，类似加减消元法"） | 「为什么这样做」——正确性论证、复杂度推导、与其他算法的比较 |
| **生成器说明** | 告知"关卡是计算机生成并验证可解的"                             | 详细解释生成策略（反向求解、挖空+验证唯一解、难度量化公式）  |
| **篇幅**       | 每节 1–3 段，总计约 300–800 字                               | 每节可多段，总计约 1000–3000 字                             |
| **LaTeX**      | 仅行内公式（`$...$`）                                        | 行内 + 块公式（`$$...$$`）+ 矩阵/表格                      |

### 2.2 LaTeX 公式书写规范

- **行内公式**：`$x_i \in \{0, 1\}$`
- **块公式**：`$$Ax = b \pmod{2}$$`
- **矩阵**：

  $$
  egin{pmatrix}
  1 & 1 & 0 \\
  1 & 1 & 1 \\
  0 & 1 & 1
  \end{pmatrix}
  $$
- **集合**：`$\mathbb{F}_2$`、`$\{0, 1\}^{n^2}$`
- **复杂度**：`$O(n^3)$`、`$\mathcal{O}(n^3)$`
- **保持一致**：同一概念全文件使用相同符号，不混用 `x` 与 `\mathbf{x}`

### 2.3 中英翻译规范

| 原则                    | 说明                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| **公式语言无关**  | LaTeX 公式在 zh-CN 和 en 文件中完全相同，不翻译数学符号                                                                                     |
| **术语首次出现**  | 中文首次出现时附英文原文：`GF(2)（二元有限域）`；英文文件反之亦可                                                                         |
| **口语化程度**    | 中文可用"我们"拉近距离；英文保持中性学术语气（avoid "let's"）                                                                               |
| **i18n key 引用** | 文件中的 UI 术语引用 i18n key 而非硬编码：`{ { ui.solve } }` → 由 ContentRenderer 替换（空格仅文档中为防模板引擎误解析，实际使用无空格） |
| **代码关键字**    | 伪代码中的关键字保留英文（`if`, `for`, `while`），注释按语言翻译                                                                      |

### 2.4 可访问性要求

- 所有图片/图示需配 `alt` 文本（zh-CN 文件用中文描述，en 文件用英文描述）
- 颜色不作为传达信息的唯一手段（色盲友好）
- LaTeX 公式需通过 KaTeX 渲染（非图片），支持屏幕阅读器

## 4. 渐进式揭示组件接口定义

`ContentRenderer` 是 `@ludus/ui` 中的核心组件，负责按 L1/L2/L3 层级渲染教学内容：

```typescript
// packages/education/src/ContentRenderer.tsx (骨架)

import type { EducationContent } from '@ludus/core/schemas';

export interface ContentRendererProps {
  /** 要渲染的教学内容（已解析的 EducationContent 对象） */
  content: EducationContent;
  /** 当前可见深度：'L1' = 仅游戏, 'L2' = 知识卡片, 'L3' = 完整教学 */
  visibleDepth: 'L1' | 'L2' | 'L3';
  /** 切换到更深层的回调 */
  onReveal: (depth: 'L2' | 'L3') => void;
  /** 求解器步骤轨迹（供 §4 可视化消费） */
  solverTrace?: SolverTrace;
  /** 语言 */
  locale: 'zh-CN' | 'en';
}
```

### 行为规范

| 层级         | 可见内容                                                                          | 入口           |
| ------------ | --------------------------------------------------------------------------------- | -------------- |
| **L1** | 仅游戏本体，零教学内容                                                            | 无（默认状态） |
| **L2** | 通关后出现"揭秘"按钮 → 展开知识卡片（§2 思考 + §3 揭示摘要 + §4 求解器演示）  | 点击"揭秘"     |
| **L3** | L2 卡片底部"深入学习"按钮 → 展开完整文档（§3 完整推导 + §4 伪代码 + §5 出题） | 点击"深入学习" |

### 渲染规则

1. **L2 卡片**：紧凑布局，至多一屏；求解器演示自动播放（可暂停）。
2. **L3 文档**：类教材排版，含目录导航；伪代码语法高亮；公式 KaTeX 渲染。
3. **关闭行为**：L2/L3 层可随时关闭回到 L1 游戏，不丢失游戏状态。
4. **语言切换**：ContentRenderer 根据 `locale` prop 加载对应语言的教学内容。
