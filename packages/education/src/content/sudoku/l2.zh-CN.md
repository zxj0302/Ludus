# 数独 Sudoku — 原理揭秘

## 1. 玩 · Play

> 数独（Sudoku）是全球最流行的逻辑填数游戏之一。标准 9×9 网格，目标是在每个空格中填入 1–9，使得每行、每列、每个 3×3 宫格中的数字都不重复。游戏开始时已有若干"已知数"（给定数字），你需要通过逻辑推理补全剩余格子。

## 2. 思考 · Think

玩了这么多关，你有没有想过：

**是不是任何有唯一解的关卡都能被人类解出来？** 不——计算机可以轻松处理的逻辑，人类可能因分支太多而放弃。**最少需要几个已知数才能保证唯一解？** 已知 17 是下限（有 17 个给定数的标准数独已存在，16 个给定数的标准数独不可能有唯一解）。

**为什么有些关卡特别难？** 因为它们的推理链条长——你需要连续推出 10+ 步才能填下一个格子，中间没有"顺手可得"的简单格。这背后是回溯搜索树的深度。

更妙的是：计算机不仅能秒解任意数独，还能**反向设计**出一个"唯一解但极难"的关卡——这背后是"精确覆盖"（Exact Cover）和 Knuth 的 DLX 算法（Dancing Links，舞蹈链）。

## 3. 揭示 · Reveal

### 形式化定义

把数独转化为一个**精确覆盖问题**：对于 9×9 的标准数独，有 729 种可能的"候选赋值"（每个格子可填 1–9）和 324 个约束条件：

| 约束类型 | 数量 | 含义 |
|---------|------|------|
| 每格一数 | 81 | 每个格子恰好填一个数字 |
| 每行不重 | 81 | 每行中 1–9 各出现一次 |
| 每列不重 | 81 | 每列中 1–9 各出现一次 |
| 每宫不重 | 81 | 每个 3×3 宫格中 1–9 各出现一次 |

729 行 × 324 列的 0-1 矩阵中，每行（候选赋值）在其对应的 4 个约束列上标 1。目标是选出一组行，使得**每一列恰好被覆盖一次**——这就是精确覆盖问题。

### 复杂度归类

- **复杂度类**：**NP-complete**（一般化到 $n \times n$）
- **论证**：拉丁方完成问题是 NP-complete 的经典结论；数独的约束更强（多了宫格约束），因此也是 NP-complete。9×9 规模很小，但其求解思路可推广到任意 $n$。

## 4. 求解 · Solve

### 两种主流方法

**方法一：回溯 + 约束传播**（直观，适合教学）
1. 选一个空格，猜测填入一个候选数字
2. 用约束（行/列/宫）更新候选列表
3. 递归深入，若冲突则回溯换下一个候选
4. 全部填满 → 找到解

**方法二：DLX（Dancing Links，舞蹈链）**（高效，Knuth 经典）
1. 将棋盘转化为 729×324 精确覆盖矩阵
2. 用交叉十字链表（toroidal doubly linked list）表示矩阵
3. 递归覆盖列 → 选行 → 覆盖冲突列 → 深入
4. 回溯时恢复（uncover）已被覆盖的节点

DLX 的核心创新在于：用链表操作代替矩阵运算，覆盖/恢复（cover/uncover）操作的时间复杂度与删除的节点数成正比，而不是矩阵大小。这是它高效的原因。
