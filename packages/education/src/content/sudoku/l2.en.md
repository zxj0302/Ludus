# Sudoku — How It Works

## 1. Play

> Sudoku is one of the world's most popular logic puzzles. The standard 9×9 grid must be filled so that each row, column, and 3×3 box contains the digits 1–9 exactly once. Some cells are pre-filled as "givens"; you must deduce the rest through logical reasoning.

## 2. Think

After solving a few puzzles, consider:

**Can every puzzle with a unique solution be solved by a human?** Not necessarily — computers can handle branching logic that would overwhelm a person. **What's the minimum number of givens needed to guarantee a unique solution?** The known lower bound is 17 — puzzles with 17 givens exist, but no 16-given standard Sudoku can have a unique solution.

**Why are some puzzles much harder than others?** Because their reasoning chains are long — you may need 10+ steps of deduction before any cell becomes obvious. The difficulty is tied to the depth of the backtracking search tree.

Even better: a computer can not only solve any Sudoku in milliseconds, but also **reverse-design** a puzzle with a unique solution that's brutally hard — powered by the "Exact Cover" formulation and Knuth's elegant DLX algorithm (Dancing Links).

## 3. Reveal

### Formal Definition

Sudoku can be transformed into an **Exact Cover problem**: for a standard 9×9 Sudoku, there are 729 possible "candidate assignments" (each cell × 9 possible values) and 324 constraints:

| Constraint Type | Count | Meaning |
|----------------|-------|---------|
| One per cell | 81 | Each cell gets exactly one digit |
| Row uniqueness | 81 | Each row contains 1–9 exactly once |
| Column uniqueness | 81 | Each column contains 1–9 exactly once |
| Box uniqueness | 81 | Each 3×3 box contains 1–9 exactly once |

In a 729×324 binary matrix, each row (candidate assignment) has a 1 in its 4 corresponding constraint columns. The goal: select a set of rows such that **every column is covered exactly once** — this is the Exact Cover problem.

### Complexity Classification

- **Complexity Class**: **NP-complete** (for generalized $n \times n$)
- **Justification**: The Latin square completion problem is a classic NP-complete result; Sudoku adds box constraints, making it also NP-complete. The 9×9 instance is tiny, but the formulation generalizes to any $n$.

## 4. Solve

### Two Main Approaches

**Method 1: Backtracking + Constraint Propagation** (intuitive, instructional)
1. Pick an empty cell, try a candidate digit
2. Update candidate lists using row/column/box constraints
3. Recurse; on conflict, backtrack and try the next candidate
4. All cells filled → solution found

**Method 2: DLX (Dancing Links)** (efficient, Knuth's classic)
1. Transform the puzzle into a 729×324 exact cover matrix
2. Represent the matrix as a toroidal doubly linked list (cross-circulating chains)
3. Recursively: cover a column → select a row → cover conflicting columns → recurse
4. On backtrack, uncover the removed nodes

DLX's key insight: linked-list operations replace matrix arithmetic. Cover and uncover operations run in time proportional to the number of nodes removed, not the full matrix size — this is why it's blazingly fast.
