# Nim 取石子 — XOR 的博弈魔法

## 1. 玩 · Play

Nim 是世界上最简单的博弈游戏之一：几堆石子，两人轮流从某一堆中取走任意数量（至少 1 颗，可以取完整堆）。取走最后一颗石子的人获胜。

试试看！你能找到战胜 AI 的秘诀吗？

## 2. 思考 · Think

- 为什么 [1, 2, 3] 这样的局面，无论你怎么走，都会输？
- 为什么 [3, 4, 5] 你却有机会赢？
- 有没有一种"万能公式"，看一眼就知道胜负？

## 3. 揭示 · Reveal

1901 年，哈佛数学家 Charles Bouton 发现了 Nim 的必胜秘诀——**Nim-sum**：

$$\text{Nim-sum} = a_1 \oplus a_2 \oplus \cdots \oplus a_k$$

其中 $\oplus$ 是 XOR（按位异或）运算。

- **Nim-sum = 0 → P 位置（Previous player win）**：上一个走的人必胜，轮到你时已经晚了
- **Nim-sum ≠ 0 → N 位置（Next player win）**：你必胜！只要找一堆，使取走后剩余的数等于 `当前堆数 XOR nim-sum`

**直觉**：XOR = 0 就像一个"完美平衡" —— 无论你怎么打破，对手都能一键恢复平衡。

## 4. 求解 · Solve

对于局面 [3, 4, 5]：

```
3 = 011 (二进制)
4 = 100
5 = 101
XOR = 010 = 2 ≠ 0 → N 位置，你必胜！

必胜走法：找堆 3 (011)
011 ⊕ 010 = 001 = 1 < 3
从堆 3 取 2 颗 → 局面变为 [1, 4, 5]
验证：1 ⊕ 4 ⊕ 5 = 000 = 0 → 对手陷入 P 位置！
```

## 5. 出题 · Create

Nim 的关卡生成简单而优雅：先随机生成一个 P 位置（Nim-sum = 0），然后随机走一步得到 N 位置作为考题。难度由堆数和石子数控制——堆越多、数字越大，XOR 心算越难。
