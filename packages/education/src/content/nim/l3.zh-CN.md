# Nim 取石子 — 完整数学与算法

## 1. 玩 · Play

Nim 是**不偏博弈（Impartial Game）**的经典代表：两个玩家、完全信息、无随机因素、同一组合法走子对双方相同。几堆石子，每回合从任一堆取任意正数颗石子（可整堆取走），取最后一颗者获胜。

## 2. 思考 · Think

### 2.1 问题

- 如何用严格数学判定任意 Nim 局面的胜负？
- Nim-sum = 0 的必胜策略，为什么总是成立？核心洞见是什么？
- 如果将 Nim 泛化为任意不偏博弈，是否也有类似的"通用解法"？
- 如何保证生成的关卡总是 N 位置（轮到玩家时能赢）？

### 2.2 直觉

XOR 的奇妙之处在于它既能捕捉"平衡"，又能给出"如何打破平衡"的指令——**XOR = 0 如同所有堆的二进制位都完美配对，任何合法的走子都会破坏某些位上的配对；而 XOR ≠ 0 时，总存在一步反击，重新让 XOR 归零。**

## 3. 揭示 · Reveal

### 3.1 形式化定义

**定义 1（Nim 局面）**：一个 Nim 局面是一个有限序列 $(a_1, a_2, \dots, a_k)$，其中 $a_i \in \mathbb{N}$ 表示第 $i$ 堆的石子数。记 $S = \{(a_1, \dots, a_k) \mid k \ge 1, a_i \in \mathbb{N}\}$。

**定义 2（合法走子）**：从局面 $(a_1, \dots, a_k)$ 出发，一次合法走子选择一个堆索引 $i$ 和一个正整数 $r$，使得 $1 \le r \le a_i$，得到新局面 $(a_1, \dots, a_i - r, \dots, a_k)$。

**定义 3（P 位置与 N 位置）**：

- **P 位置（Previous-player winning position）**：轮到该玩家时，若其所有合法走子都导致对方必胜，则该位置为 P 位置。
- **N 位置（Next-player winning position）**：轮到该玩家时，若存在至少一个合法走子使得对方陷入 P 位置，则该位置为 N 位置。

递归地：
- 终局局面 $(0, 0, \dots, 0)$ 是 **P 位置**（上一位玩家已取走最后一颗石子，当前玩家无棋可走，即输）。
- 局面 $p$ 是 N 位置 $\iff \exists$ 合法走子到某个 P 位置。
- 局面 $p$ 是 P 位置 $\iff \forall$ 合法走子都到 N 位置。

### 3.2 Bouton 定理

> **Bouton 定理（1901）**：一个 Nim 局面 $(a_1, \dots, a_k)$ 是 **P 位置** 当且仅当其 Nim-sum 为零：
> $$a_1 \oplus a_2 \oplus \cdots \oplus a_k = 0$$
> 其中 $\oplus$ 是按位异或（XOR）运算。

#### 证明（归纳法）

对堆中石子总数 $N = \sum_{i=1}^k a_i$ 施归纳。

**基例**：$N = 0$，即 $(0, 0, \dots, 0)$。Nim-sum = 0，该局面为 P 位置（无合法走子）。基例成立。

**归纳假设**：对所有石子总数 $< N$ 的局面，Bouton 定理成立。

**归纳步**：考虑局面 $p = (a_1, \dots, a_k)$，石子总数 $N > 0$。

需证明两个方向：

**(⇒) 若 Nim-sum = 0，则 p 是 P 位置。**

由归纳假设，需证：从 Nim-sum = 0 出发的所有合法走子都到达 Nim-sum ≠ 0 的局面。

取第 $i$ 堆，从中移除 $r$ 颗石子（$1 \le r \le a_i$）。新堆大小为 $a_i' = a_i - r$。新 Nim-sum 为：

$$s' = a_1 \oplus \cdots \oplus a_i' \oplus \cdots \oplus a_k$$

由于 XOR 是自逆的（$x \oplus x = 0$），有：

$$s' = s \oplus a_i \oplus a_i' \quad \text{其中 } s = \text{原 Nim-sum} = 0$$

$$s' = 0 \oplus a_i \oplus a_i' = a_i \oplus a_i'$$

由于 $a_i \neq a_i'$（因为 $r \ge 1$），$a_i \oplus a_i' \neq 0$。因此 $s' \neq 0$。

所以从 Nim-sum = 0 出发，任一合法走子都到达 Nim-sum ≠ 0 的局面。由归纳假设，这些后继局面都是 N 位置。故当前局面是 P 位置。

**(⇐) 若 Nim-sum ≠ 0，则 p 是 N 位置。**

设 $s = a_1 \oplus \cdots \oplus a_k \neq 0$。需证存在一个合法走子到达 Nim-sum = 0 的局面。

令 $d$ 为 $s$ 的最高非零位。由于 $s \neq 0$，$d$ 存在且 $2^d \le s < 2^{d+1}$。

因为 $s$ 的第 $d$ 位为 1，而 $s$ 是所有 $a_i$ 的 XOR，所以必有至少一个 $a_i$ 的第 $d$ 位也为 1。选此 $a_i$。

令 $a_i' = a_i \oplus s$。由于 $a_i$ 的第 $d$ 位为 1 而 $s$ 的第 $d$ 位也为 1，XOR 后该位变为 0，因此 $a_i' < a_i$（最高不同位从 1 变 0，数值减小）。此外 $a_i' \ge 0$。

设移除量 $r = a_i - a_i'$，则 $1 \le r \le a_i$。从第 $i$ 堆移除 $r$ 颗后得到新 Nim-sum：

$$s' = s \oplus a_i \oplus a_i' = s \oplus a_i \oplus (a_i \oplus s) = s \oplus a_i \oplus a_i \oplus s = 0$$

成功构造了一个到 Nim-sum = 0 局面的合法走子。由归纳假设，该后继是 P 位置。故当前局面是 N 位置。

**证毕。**

> **推论**：Bouton 定理给出了一个 $O(k)$ 时间、$O(1)$ 空间的胜负判定算法（$k$ 为堆数），以及线性时间内构造必胜策略的方法。

### 3.3 XOR 的代数性质

Nim-sum 使用的 XOR 运算具有以下关键性质，支撑着整个理论：

| 性质 | 公式 | 说明 |
|------|------|------|
| **交换律** | $a \oplus b = b \oplus a$ | 顺序无关 |
| **结合律** | $(a \oplus b) \oplus c = a \oplus (b \oplus c)$ | 可任意分组 |
| **幺元** | $a \oplus 0 = a$ | 0 是单位元 |
| **自逆** | $a \oplus a = 0$ | 每个元素是自己的逆元 |
| **消去律** | $a \oplus b = a \oplus c \Rightarrow b = c$ | 两边 XOR $a$ 即得证 |

自逆性质是 Nim 的核心：P 位置（XOR = 0）的任何打破都会产生非零，而非零位置总能通过一次 XOR 操作归零——**XOR 的自逆性 =「完美平衡 - 打破 - 修复」的三段论**。

### 3.4 Sprague-Grundy 定理

Bouton 定理解的是 Nim 的胜负判定。Sprague-Grundy 定理（1935-1939）将这一思路推广到了 **所有不偏博弈**：

> **定理（Sprague-Grundy）**：每个不偏博弈的每个局面都等价于一个 Nim 堆，其大小为该局面的 Grundy 数 $g$。多个不偏博弈的不交和等于各 Grundy 数的 XOR。局面为 P 位置当且仅当其 Grundy 数为 0。

#### Grundy 数的递归定义

$$g(p) = \operatorname{mex}\{g(q) \mid q \text{ 是 } p \text{ 的后继局面}\}$$

其中 $\operatorname{mex}$（minimum excludant）是最小不包含的非负整数。

对于 Nim 本身，堆大小为 $n$ 的单堆 Grundy 数恰为 $n$（因为 $n$ 的后继是 $0, 1, \dots, n-1$，其 $\operatorname{mex} = n$）。因此 Nim 的多个堆 = Grundy 数的 XOR，与 Bouton 定理完全一致。

**意义**：Sprague-Grundy 将任意不偏博弈转化为 Nim——任何不偏博弈的求解都可归结为计算 Grundy 数。这是组合博弈论里程碑式的结论。

### 3.5 复杂度归类

- **复杂度类**：**P**（多项式时间可解）
- **关键论证**：
  - 判定 P/N 位置：$O(k)$（一次 XOR 遍历）
  - 构造必胜策略：$O(k)$（找第 $d$ 位为 1 的堆）
  - 空间复杂度：$O(1)$（仅需记录当前 Nim-sum 和最佳走法索引）
- **对比**：由于 Nim 的极简数学结构（XOR），它在所有不偏博弈中享有最高效的求解算法。一般不偏博弈的 Grundy 数计算可能为指数时间。

## 4. 求解 · Solve

### 4.1 Nim-sum 求解器

Nim 的求解器是极简的，仅需一次 XOR 遍历和一回合的走法构造：

```typescript
function computeNimSum(piles: number[]): number {
  return piles.reduce((a, b) => a ^ b, 0);
}

function isPPosition(piles: number[]): boolean {
  return computeNimSum(piles) === 0;
}

function findWinningMove(piles: number[]): NimMove | null {
  const nimSum = computeNimSum(piles);
  if (nimSum === 0) return null;          // P-position → no winning move
  for (let i = 0; i < piles.length; i++) {
    const target = piles[i]! ^ nimSum;    // a_i' = a_i ⊕ s
    if (target < piles[i]!) {
      return { pileIndex: i, removeCount: piles[i]! - target };
    }
  }
  return null;
}
```

#### 流程

1. 计算所有堆的 XOR → 得到 Nim-sum $s$
2. 若 $s = 0$ → 返回无必胜走法（P 位置）
3. 若 $s \neq 0$ → 遍历各堆，找到满足 `piles[i] ⊕ s < piles[i]` 的堆 $i$
4. 从该堆移除 `piles[i] - (piles[i] ⊕ s)` 颗石子

#### 复杂度分析

| 指标 | 值 |
|------|-----|
| 时间复杂度 | $O(k)$，$k$ 为堆数 |
| 空间复杂度 | $O(1)$ |
| 胜负判定 | 一次 XOR，$O(k)$ |
| 必胜走法构造 | $O(k)$（最坏遍历所有堆） |
| 求解器输出 | 一个胜着（若存在）或空（无胜算） |

### 4.2 示例求解

考虑局面 [3, 4, 5]：

```
3 = 011₂
4 = 100₂
5 = 101₂
s = 010₂ = 2 ≠ 0 → N-position

找堆：3 XOR 2 = 1 < 3 ✓
走法：从堆 3 取 2 → [1, 4, 5]
验证：1 ⊕ 4 ⊕ 5 = 000₂ = 0 → P-position ✓
```

考虑局面 [1, 2, 3]：

```
1 = 01₂
2 = 10₂
3 = 11₂
s = 00₂ = 0 → P-position

尝试各堆：
  1 ⊕ 0 = 1 ≥ 1 ✗
  2 ⊕ 0 = 2 ≥ 2 ✗
  3 ⊕ 0 = 3 ≥ 3 ✗
无合法必胜走法 → 当前局面必败。
```

## 5. 出题 · Create

> 与 §3"形式化定义"不同，§5 的核心问题是：**如何保证生成的 Nim 关卡合理且难度可控**？

### 5.1 保证一：可解性（N 位置）

#### 问题

生成的初始局面必须是 **N 位置**——轮到玩家时存在必胜走法。

#### 判定

$$ \text{Nim-sum} = a_1 \oplus a_2 \oplus \cdots \oplus a_k \neq 0 $$

即 XOR 结果非零。

#### 生成保证

**P-距离一步法（P-distance walk，默认策略）**：

1. **生成 P 位置**：随机生成 $k-1$ 个堆，计算其 XOR 值作为第 $k$ 堆。若该值在 $[1, \text{maxStone}]$ 范围内，则所有 $k$ 堆构成一个合法的 P 位置。
2. **走一步**：随机选一个非空堆，从中移除至少 1 颗但保留至少 1 颗（也可整堆取走只要不是最后一堆的唯一石子），使 Nim-sum ≠ 0。
3. **结果**：玩家面对一个 N 位置，存在至少一步必胜走法。

```
function generateLevel(config):
    1. k = pileCountFromDifficulty(config)
    2. maxS = maxStoneFromDifficulty(config)
    3. repeat:
        生成 k-1 个随机堆
        设第 k 堆 = XOR(前 k-1 堆)
    4.   until 第 k 堆 ∈ [1, maxS]     // 合法的 P 位置
    5. 选一个非空堆，移除随机石子数   // P → N 位置
    6. 返回初始局面
```

> **结论**：P-距离一步法从源头保证可解性（玩家面对 N 位置）。这是 Nim 生成器的默认策略。

---

### 5.2 保证二：唯一解

#### 问题

N 位置是否只有一个必胜走法，还是可能有多个？

#### 判定

一个 N 位置可能有多个必胜走法。例如局面 [3, 4, 5]（Nim-sum = 2）：

```
堆 3: 3 ⊕ 2 = 1 < 3 → 取 2 颗 ✓
堆 4: 4 ⊕ 2 = 6 ≥ 4 ✗
堆 5: 5 ⊕ 2 = 7 ≥ 5 ✗
→ 仅一个必胜走法
```

但局面 [2, 2, 1]（Nim-sum = 1）：

```
堆 2: 2 ⊕ 1 = 3 ≥ 2 ✗
堆 2: 2 ⊕ 1 = 3 ≥ 2 ✗
堆 1: 1 ⊕ 1 = 0 < 1 → 取 1 颗 ✓
→ 仍仅一个必胜走法
```

**一般情况**：必胜走法的数量等于满足 $a_i \oplus s < a_i$ 的堆数 $i$，其中 $s = \text{Nim-sum}$。由于 $s$ 的最高位对应的二进制位在至少一个 $a_i$ 中也为 1，因此至少有一个必胜走法。但可能多于一个。

Nim 的关卡生成不求唯一解——玩家只需找到 **任意一个** 必胜走法即可获胜。

---

### 5.3 保证三：已知最优解

#### 问题

对于 Nim，最优解的定义是什么？

#### 定义

Nim 的最优目标不是"最少步数"（因为游戏可能在 1 步内结束），而是 **最简明地引导对手进入 P 位置**。Bouton 定理给出的构造法天然产生了一个必胜走法——不需要搜索或优化。

- **唯一必胜走法**：当只有一个堆满足 $a_i \oplus s < a_i$ 时，该走法就是最优。
- **多个必胜走法**：从任意满足条件的堆中移除对应数量，都等价于把 Nim-sum 归零。从"最简洁"的角度，移除量最少的走法或从最大堆中移除可认为是"最优"（使对手的计算最为困难）。
- **optimalSteps = 1**：因为 Nim 的求解器输出的是 **一步走法**——给出从当前 N 位置到 P 位置的移动。玩家走完后，游戏进入 P 位置，对手理论上必败。

#### 生成保证

P-距离一步法天然保证：从生成的 N 位置出发，存在至少一个走法回到 P 位置。求解器在 $O(k)$ 时间内可找到其中任意一个，输出为 `moves.length = 1`。

### 5.4 保证四：难度可控

#### 问题

如何量化 Nim 局面的难度并精确控制？

#### 难度因素体系

| 因素 | 符号 | 量化方法 | 对难度的影响 | 可控性 |
|------|------|---------|-------------|--------|
| 堆数 | $k$ | 堆的总数量 | $k$ 越大，XOR 心算越复杂。$k=2$ 时 XOR 简化为相等判定（异堆等值时为 P 位置）；$k\ge 3$ 需要完整二进制计算 | **连续可调**（1-5 堆） |
| 最大石子数 | $\max(a_i)$ | 堆的最大石子数 | 数字越大→二进制位越多→XOR 计算越困难。小数字（1-7）只需 3 位二进制；大数字（8-15）需要 4 位 | **连续可调** |
| 数字分布 | — | 石子数的分布形态 | 均匀分布 vs 极差大的分布：极差大时，高位对齐困难→XOR 更难心算 | **间接可控** |
| 必胜走法的隐蔽性 | — | $a_i \oplus s$ 相对于 $a_i$ 的差距 | 移除量占原堆比例适中时"合理"；移除量极小（如取 1 颗）或极大（几乎取完整堆）时容易被发现 | **间接可控** |

#### 难度档位映射

| 档位 | 堆数 | 最大石子 | 二进制位数 | 心算难度 |
|------|------|---------|-----------|---------|
| 🟢 入门 | 2 | 3-5 | 2-3 位 | 简单：只需判断两堆是否相等 |
| 🟡 简单 | 2-3 | 5-8 | 3 位 | 稍复杂：少量堆，低位数 XOR |
| 🟠 中等 | 3 | 8-12 | 3-4 位 | 中等：3 堆需要完整二进制对齐 |
| 🔴 困难 | 3-4 | 8-15 | 3-4 位 | 困难：4 堆分散注意力 |
| ⚫ 专家 | 4-5 | 8-15 | 3-4 位 | 专家：5 堆的心算负担显著增加 |

#### 生成器如何实现难度控制

```
function generateLevel(targetDifficulty):
    1. k = mapToPileCount(targetDifficulty)
    2. maxS = mapToMaxStone(targetDifficulty)
    3. (a_1, ..., a_k) = generatePPosition(k, maxS)
    4. walk 1 step to N-position
    5. 返回 { piles, difficulty: computeScore(k, maxS) }
```

#### 难度分计算公式

$$\text{score} = \alpha \cdot \frac{k - 1}{4} + \beta \cdot \frac{\max(a_i)}{15}$$

其中 $\alpha = 50$，$\beta = 50$ 为经验权重。$\max(a_i) \le 15$ 时分数在 0-100 区间内。当堆数从 2 增加到 5，最大化石子数从 3 增加到 15，难度分从最低平滑过渡到最高。

#### 难度验证闭环

生成的每个关卡在发布前，须经过以下验证：

1. **N 位置验证**：Nim-sum ≠ 0（当前玩家有必胜策略）。
2. **Nim-sum 正确计算**：所有堆的 XOR 值与求解器结果一致。
3. **至少一个必胜走法存在**：求解器能返回一个合法走法。
4. **该走法确实使 Nim-sum 归零**：执行走法后验证新 Nim-sum = 0。
5. **难度分正确**：堆数和最大石子数在目标档位范围内。
