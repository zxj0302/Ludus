## 1. 玩 · Play

Wythoff 博弈规则：

- 两堆石子，数量分别为 $a$ 和 $b$，每堆最多 10 颗
- 每次操作：
  1. 从**一堆**中取走任意正整数颗
  2. 从**两堆**中取走**相同的**正整数颗
- 取走最后一颗石子者胜（normal play）
- 属于**不偏博弈**（impartial game）：两方走法相同

## 2. 思考 · Think

Wythoff 博弈的 P 位置分布有着惊人的规律性。

**Beatty 定理**：若 $\alpha, \beta > 1$ 是无理数且 $\frac{1}{\alpha} + \frac{1}{\beta} = 1$，则序列 $\lfloor n\alpha \rfloor$ 和 $\lfloor n\beta \rfloor$ 构成正整数的一个划分。

对于 Wythoff 博弈，$\alpha = \varphi = \frac{1 + \sqrt{5}}{2}$（黄金比例），$\beta = \varphi^2 = \varphi + 1$。这两个数满足 Beatty 条件：

$$\frac{1}{\varphi} + \frac{1}{\varphi^2} = \frac{1}{\varphi} + \frac{1}{\varphi + 1} = (\varphi - 1) + (2 - \varphi) = 1$$

## 3. 揭示 · Reveal

### 形式化定义

**Wythoff 博弈** 是完全信息的二人零和不偏博弈：

- 状态：$(a, b) \in \mathbb{N}^2$
- 允许走法：
  - $(a - k, b)$，$1 \le k \le a$
  - $(a, b - k)$，$1 \le k \le b$
  - $(a - k, b - k)$，$1 \le k \le \min(a, b)$
- 终态：$(0, 0)$，最后取走石子者胜

### P 位置刻画

**定理（Wythoff, 1907）**：$(a, b)$ 是 Wythoff 博弈的 P 位置当且仅当

$$(a, b) = (\lfloor k\varphi \rfloor, \lfloor k\varphi^2 \rfloor) \text{ 或对称形式}$$

其中 $\varphi = \frac{1 + \sqrt{5}}{2}$，$k = 0, 1, 2, \ldots$

**等价判定**：设 $a \le b$，令 $k = b - a$，则 $(a, b)$ 是 P 位置当且仅当

$$a = \lfloor k \cdot \varphi \rfloor$$

### 复杂度

- 判定 O(1)（黄金比例乘法 + floor）
- 寻找必胜走法 O(maxPile)（枚举所有走法并检查是否到达 P 位置）

Wythoff 博弈属于 P 类——必胜策略可在多项式时间内计算。

## 4. 求解 · Solve

### 算法

```
function solveWythoff(state):
  (a, b) = state.piles
  确保 a ≤ b
  k = b - a
  isP = (a == floor(k * φ))
  if isP: return { moves: [] }  // P 位置，无必胜走法
  // 枚举所有走法，选剩余石子最少的 P 位置
  for each single-pile move (i, r):
    if new position is P and remaining < best: remember it
  for each both-pile move (r):
    if new position is P and remaining < best: remember it
  return best move
```

### AI 对手

AI 始终尝试走必胜走法（通过 `findWythoffWinningMove`）。若当前为 P 位置（无必胜走法），AI 从较大堆取 1 颗，保留更多石子使局势更复杂。

> **注意**：求解器选择的"剩余石子最少"走法不等于保证最小化获胜步数。对手在 P 位置可能拖延（如只取 1 颗），拉长游戏。严格最小步数需要 **minimax 搜索**，从终态逆向计算每个状态的必胜深度，复杂度 $O(状态空间)$，对 Wythoff 随石子数二次增长，虽可接受但非必要。当前启发式保证一步到 P 位置，实践已足够。

### 与 Nim 的对比

| 特性 | Nim | Wythoff |
|------|-----|---------|
| 堆数 | 任意 | 固定 2 |
| 走法 | 仅单堆取 | 单堆取 + 同时取 |
| P 判定 | XOR = 0 | a = ⌊k·φ⌋ |
| 核心定理 | Bouton (1901) | Wythoff (1907) |
| 数学对象 | Nim-sum ⊕ | 黄金比例 φ |

## 5. 出题 · Create

生成器使用随机生成法：

1. 随机生成两堆石子（每堆 1–10 颗）
2. P 位置和 N 位置自然分布
3. 玩家观察布局后自选先后手

难度公式：$\text{score} = \frac{\max(a, b)}{10} \times 100$，clamp 到 [0, 100]。

先手假设：玩家可根据当前 P/N 位置自由选择先后手，总能选择有利位置（N→先手，P→后手）。
