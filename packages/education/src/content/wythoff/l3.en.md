## 1. Play · Play

Wythoff's game rules:

- Two piles of stones, with counts $a$ and $b$, up to 10 each
- On each turn:
  1. Remove any positive number from **one** pile
  2. Remove the **same** positive number from **both** piles
- The player taking the last stone wins (normal play)
- This is an **impartial game**: both players have the same moves

## 2. Think · Think

The P-positions of Wythoff's game exhibit striking regularity.

**Beatty's Theorem**: If $\alpha, \beta > 1$ are irrational and $\frac{1}{\alpha} + \frac{1}{\beta} = 1$, then the sequences $\lfloor n\alpha \rfloor$ and $\lfloor n\beta \rfloor$ partition the positive integers.

For Wythoff's game, $\alpha = \varphi = \frac{1 + \sqrt{5}}{2}$ (the golden ratio), $\beta = \varphi^2 = \varphi + 1$. These satisfy the Beatty condition:

$$\frac{1}{\varphi} + \frac{1}{\varphi^2} = \frac{1}{\varphi} + \frac{1}{\varphi + 1} = (\varphi - 1) + (2 - \varphi) = 1$$

## 3. Reveal · Reveal

### Formal Definition

**Wythoff's game** is a perfect-information two-player zero-sum impartial game:

- State: $(a, b) \in \mathbb{N}^2$
- Legal moves:
  - $(a - k, b)$, $1 \le k \le a$
  - $(a, b - k)$, $1 \le k \le b$
  - $(a - k, b - k)$, $1 \le k \le \min(a, b)$
- Terminal: $(0, 0)$, last mover wins

### P-position Characterization

**Theorem (Wythoff, 1907)**: $(a, b)$ is a P-position in Wythoff's game iff

$$(a, b) = (\lfloor k\varphi \rfloor, \lfloor k\varphi^2 \rfloor) \text{ or symmetric}$$

where $\varphi = \frac{1 + \sqrt{5}}{2}$, $k = 0, 1, 2, \ldots$

**Equivalent check**: Let $a \le b$, $k = b - a$. Then $(a, b)$ is a P-position iff

$$a = \lfloor k \cdot \varphi \rfloor$$

### Complexity

- Position test: O(1) (golden ratio multiplication + floor)
- Finding winning move: O(maxPile) (enumerate all moves, check P-position)

Wythoff's game is in P — the winning strategy is computable in polynomial time.

## 4. Solve · Solve

### Algorithm

```
function solveWythoff(state):
  (a, b) = state.piles
  ensure a ≤ b
  k = b - a
  isP = (a == floor(k * φ))
  if isP: return { moves: [] }  // P-position, no winning move
  // enumerate all moves, pick the one with fewest remaining stones
  for each single-pile move (i, r):
    if new position is P and remaining < best: remember it
  for each both-pile move (r):
    if new position is P and remaining < best: remember it
  return best move
```

### AI Opponent

The AI always tries to play a winning move (via `findWythoffWinningMove`). If in a P-position (no winning move exists), the AI removes 1 from the larger pile, keeping more stones for a more complex position.

> **Note**: "Fewest remaining stones" does NOT guarantee the minimum number of plies to win. The opponent in a P-position may delay (e.g., taking 1 stone per turn), stretching the game. Strict move minimization requires **minimax search** — computing winning depth for each state via retrograde analysis from terminal positions. Complexity is $O(n^2)$ in max pile size for Wythoff (quadratic state space), tractable but unnecessary. The current heuristic guarantees the core objective: reaching a P-position in one move.

### Comparison with Nim

| Property | Nim | Wythoff |
|----------|-----|---------|
| Piles | Arbitrary | Fixed 2 |
| Moves | Single pile only | Single + both piles |
| P test | XOR = 0 | a = ⌊k·φ⌋ |
| Core theorem | Bouton (1901) | Wythoff (1907) |
| Key object | Nim-sum ⊕ | Golden ratio φ |
