# Lights Out — How It Works

## 1. Play

> Tip: Tap a cell to toggle itself and its four orthogonal neighbors. Turn all lights off to win.

## 2. Think

After a few levels, you might wonder: **can any starting configuration be solved?** If so, what is the minimum number of presses? If not, why not?

Even better: the computer can instantly solve any board — and **reverse-engineer** a puzzle with exactly one solution just for you. An elegant mathematical structure makes all this possible.

## 3. Reveal

### Formal Definition

Flatten the $n \times n$ board into an $n^2$-dimensional vector over $\{0, 1\}$:
- **OFF = 0**, **ON = 1**.
- Pressing a cell toggles it and its neighbors via **addition modulo 2** (XOR): $1+1=0$.

Key observations:
- **Order doesn't matter** — pressing A then B yields the same result as B then A.
- **Pressing twice = no press** — because $1+1=0 \pmod{2}$.

Thus the problem reduces to:

> Given an initial state vector $\mathbf{b}$, find a press vector $\mathbf{x}$ such that $A\mathbf{x} = \mathbf{b} \pmod{2}$,

where $A$ is the $n^2 \times n^2$ "influence matrix": $A_{ij}=1$ means pressing cell $j$ toggles cell $i$.

### Complexity Classification

- **Complexity Class**: **P** (polynomial-time solvable)
- **Justification**: This is a system of linear equations over GF(2) — the Galois field of two elements. Gaussian elimination solves it in $O(n^6)$ time (naive). For the classic $5 \times 5$ board, this takes milliseconds.

## 4. Solve

### Algorithm: Gaussian Elimination over GF(2)

The core idea is identical to solving linear equations in high school — **eliminate variables row by row**, except addition is replaced by XOR.

1. Form the **augmented matrix** $[A \mid \mathbf{b}]$.
2. For each column, find a pivot row (first row with a 1 in that column), then XOR it with all rows below that also have a 1 in that column.
3. After elimination, back-substitute from bottom to top.
4. If any row has all zeros on the left and a 1 on the right, the system is **inconsistent** — that starting board can never be solved!

### Complexity Analysis

- Time: $O(n^6)$ naive; can be optimized to $O(n^4)$ by exploiting sparsity
- Space: $O(n^4)$
