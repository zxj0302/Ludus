# Grundy's Game — 完整数学与算法

## 1. 玩 · Play

**Grundy's Game**（normal play）：状态为有限多重集 $\{n_1,\ldots,n_k\}$，$n_i\ge 1$。

合法走子：选 $n_i\ge 3$，替换为 $a,b$，满足 $a+b=n_i$、$a,b\ge 1$、$a\neq b$（实现取 $1\le a\le\lfloor(n_i-1)/2\rfloor$）。

终局：$\forall i,\; n_i\le 2$（无合法走子）→ 当前玩家负。

Hub：`phase: 'choosing'` 选先后手；胜负与 **Nim 同构**（终局后 `currentPlayer` 为无棋方可走的一方；人类刚走完则 `currentPlayer===1`）。

## 2. 思考 · Think

### 2.1 问题

- 如何严格定义单堆 $g(n)$？多堆为何是 XOR？
- $g(n)$ 序列是否最终周期？（开放问题；非本模块目标）
- 生成器如何偏向 P/N？

### 2.2 直觉

拆堆把一个分量换成两个独立分量的**不偏和**；Sprague–Grundy 说其值恰为 $g(a)\oplus g(b)$。对所有合法拆法取 mex，得到 $g(n)$。

## 3. 揭示 · Reveal

### 3.1 形式化

**定义（单堆）**：

$$g(n)=\operatorname{mex}\{g(a)\oplus g(b)\mid a+b=n,\,a>0,\,b>0,\,a\neq b\}$$

**定理（局面）**：多堆局面为 P $\iff$ $g(n_1)\oplus\cdots\oplus g(n_k)=0$。

### 3.2 与 Nim / Euclid / Wythoff

| | Nim | Euclid | Wythoff | Grundy（本模块） |
|--|-----|--------|---------|------------------|
| 走法 | 单堆任意取 | 大堆减小堆倍数 | 单堆或两堆同数 | 一堆拆两堆不等 |
| 判定 | 堆大小 XOR | φ 区间 | Beatty | **nimber** XOR |
| 教学点 | Bouton | φ / gcd | φ / Beatty | **SG 定理本体** |

### 3.3 实现口径

- 记忆化 `computeGrundy(n)`；Hub 关卡 $n\le 24$。
- 单元测试对照 OEIS [A002188](https://oeis.org/A002188) 前缀（$n=0..20$）。
- 周期性猜想见 *Winning Ways* / Flammenkamp 表 — **不**在本模块证明。

## 4. 求解 · Solve

### 4.1 核心 API

```typescript
// packages/games/src/grundys-game/solver.ts
computeGrundy(n)           // mex 递推
computeGrundyXor(piles)    // ⊕ g(n_i)
findWinningMove(piles)     // 拆到 XOR=0
solveGrundysGame(state)    // 整局序列 + playerStarts
```

### 4.2 选先后手与回放

`choosing` 时：`playerStarts = (XOR ≠ 0)`。必须写入 `visualizationData.playerStarts`（Hub `getPlayerStarts` 缺省为 true）。

### 4.3 复杂度

| 操作 | 复杂度 |
|------|--------|
| 填 $g(0..N)$ | $O(N^2)$ |
| 一步必胜 | $O(\sum \lfloor n_i/2\rfloor)$ |
| 整局 | $O(\text{深度}\times\text{每步合法数})$ |
