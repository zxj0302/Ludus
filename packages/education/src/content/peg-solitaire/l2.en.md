## 1. Play

Peg Solitaire’s rule is a nursery rhyme: jump a peg orthogonally over a neighbor into an empty hole and remove the jumped peg. Every move reduces the peg count by one.

**Hook 1: the last jumps are often a verdict, not a victory lap.** A board with five lonely pegs can already be dead.

This build uses the English 33-hole cross. Levels come from a **classic catalog** (no random dig generator). Play UX mirrors Sokoban: **pick a mode, then pick a named level** — no difficulty slider.

- **Leave one:** exactly one peg anywhere
- **Center one:** exactly one peg in the center (includes classic center-vacant)

The two mode lists are **not** the same set: each puzzle declares one goal. Many textbook figures (Greek Cross, pyramid, arrow…) are solvable for “leave one” but **not** for “center one,” so they only appear under Leave one.

**Two win goals:**

| Goal | Meaning |
|------|---------|
| One anywhere | Exactly one peg remains, in any hole |
| One in center | Exactly one peg remains, and it must occupy the center |

**Rigorous claim 1: each move decreases the peg count by exactly 1.** Clearing `from`/`over` and filling `to` yields a net $-1$. From the classic 32-peg center-vacant start to a singleton, any complete solution needs exactly 31 single jumps (Bergholt’s famous “18 moves” counts multi-jumps differently).

## 2. Think

**Hook 2: “jump into the nearest hole” is a bad habit.** Nearby empties often carve the board into islands.

Compare the goals:

- **One anywhere:** the terminal hole is free; more finishing shapes can count as wins.
- **One in center:** the terminal hole is fixed; this is the cultural classic. On the English board, the final jump from a center-vacant campaign often offers a choice between center and edge-center — a textbook/community observation, not a new theorem from this repo.

Mini-challenge: take one residual and tighten the goal from “anywhere” to “center.” Solvability can disappear because the accepting set shrinks.

## 3. Reveal

Thirty-three holes → a bitmask. A jump flips three bits. The naïve state-space bound is $2^{33}$; the reachable subset is far smaller.

UI hole labels: columns a–g (left→right), rows 1–7 (top→bottom); center = **d4** (same notation as move lists and viz edge labels).

**Hook 3: symmetry is a cheat code.** D4 (rotations + reflections) collapses look-alike boards so search wastes less effort.

Historically some players relax to “≤3 pegs left.” This game **does not** offer that as a playable goal; education only mentions it so it is not confused with the classic catalog goals.

## 4. Solver

**Not BFS-only.** This build uses:

| Case | Algorithm | Question answered |
|------|-----------|-------------------|
| Few pegs (~≤10) or explicit shortest | **BFS + D4** | Shortest path (practical on shallow boards) |
| Deeper boards (default) | **DFS + D4 + time budget** | Reachability (find any legal route first) |

Both share bitmask states, D4 canonical keys, and a Web Worker so the UI stays responsive. Timeouts are honest — “not found in budget” is **not** reported as “unsolvable.”

**Key insight: for leave-one / center-one goals, length is not the mystery.** Every legal route from $n$ pegs to 1 peg has length exactly $n-1$. The hard part is **reachability**, not shaving moves. Bergholt’s “18 moves” merges multi-jumps — a different counting convention.

The viz shows a **sampled tree** (amber principal variation + a few grey side branches), not the full state space.

Catalog length 31 (classic center-vacant) is the single-jump literature count; a Worker timeout on the full board does not mean this run re-proved optimality.

## 5. Create

There is no “invent a random level” button. The toolbar works like Sokoban: **mode (leave one / center one) + named catalog levels**.

- Each entry carries its own goal and optional known length.
- `uniqueSolution: false`: we guarantee reachability of the declared goal, not uniqueness or unique shortestness.

**Hook 5: good puzzles are magic; bad puzzles are broken locks.** The catalog’s bar is “named / verified solvable,” not “whatever the digger emitted today.”
