# 欧几里得博弈 — 黄金比例里的必胜秘诀

## 1. 玩 · Play

两堆石子。每回合从**大堆**减去**小堆的整数倍**（至少 1 倍，也可以一次减光整堆大堆）。减完后两堆重新排序（大在前）。谁让大堆变成 0，谁就赢。

你可以选先走或让 AI 先走。默认局面 [34, 21]——你能找到必胜倍数吗？

## 2. 思考 · Think

- 为什么 [3, 2] 这样的局面，轮到先手时往往已经晚了？
- 为什么 [5, 3] 你却有机会一步把对手送进必败区？
- 这和小学学过的**辗转相除法**有什么关系？
- 有没有不用穷举每一步的「一眼判胜负」公式？

## 3. 揭示 · Reveal

每一步都像在做「减法版辗转相除」：从大数里减掉若干倍小数。

**败者态（P 位置）** 可以用黄金比例 $\varphi = \frac{1+\sqrt{5}}{2} \approx 1.618$ 判定。设规范化局面为 $(a, b)$，$a \ge b > 0$：

| 条件 | 判定 |
|------|------|
| $a = b$ | **N**：一步取光即胜 |
| $a > b$ 且 $\lfloor b\varphi \rfloor \ge a$ 且 $a < b\varphi$ | **P**：轮到的人必败 |
| 其他 | **N**：存在必胜走法 |

**直觉**：当大堆「刚好卡」在 $\varphi$ 倍小堆附近时，你怎么减都会把对手送进有利局面；反之，你总能一步把对手推入 P 位置。

与 **Nim**（XOR）、**Wythoff**（Beatty 序列）不同，这里的主角是 **gcd / 欧几里得结构 + φ**。

## 4. 求解 · Solve

**例 1 — P 位置 [3, 2]**

```
⌊2·φ⌋ = ⌊3.236⌋ = 3
3 ≤ 3 且 3 < 3.236 → P 位置
合法 k 只有 1：3−1×2 = 1 → [2,1]（N）
没有一步能让对手陷入 P → 先手必败（完美对弈下）
```

**例 2 — N 位置 [13, 5]**

```
⌊5·φ⌋ = ⌊8.09⌋ = 8
8 < 13 → N 位置

合法 k：1, 2
k=2：13 − 2×5 = 3 → [5, 3]
验证 [5,3]：⌊3·φ⌋=4，4≥3 且 3<4.854 → P ✓

必胜走法：取 2 倍（−10）
```

求解器对当前局面 O(1) 判 P/N，再枚举至多 $\lfloor a/b \rfloor$ 个倍数找必胜步；侧边栏可演示整局最优序列。

**选先后手提示**：N 位置建议你先走；P 位置建议让 AI 先走。

## 5. 出题 · Create

生成器按难度范围采样 $(a,b)$：

- **简单**：偏向 N 位置（先手有利）
- **困难**：偏向 P 位置（后手有利）

用 `seed` 可复现同一对石子。换关 = 新的 $(a,b)$ + 重新选先后手。
