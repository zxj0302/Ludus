# 欧几里得博弈 — 完整数学与算法

## 1. 玩 · Play

**欧几里得博弈（减法倍数版）**是两堆、完全信息、无随机的**不偏博弈**：状态为有序对 $(a,b)$，$a \ge b \ge 0$。

合法走子：选整数 $k$，$1 \le k \le \lfloor a/b \rfloor$，令 $a' = a - kb$。若 $a'=0$ 则当前玩家**立即获胜**；否则新状态为 $\text{normalize}(a', b)$。

**本 Hub 终局口径（与 Nim 不同）**：

- 胜负条件是「清空大堆」，不是「取走最后一颗且局面变为 (0,0)」。
- 实现上胜方**不换手**（`currentPlayer` 保持），以便 `isPlayerVictory` 判定。
- 选先后手：`phase: 'choosing'`，与 Nim 相同。

## 2. 思考 · Think

### 2.1 问题

- 如何用闭式或近闭式判定 P/N，而不做完整博弈树？
- 减法步与欧几里得算法 $\gcd(a,b)$ 有何对应？
- 生成器如何保证难度曲线（P 密度 vs 堆大小）？
- 选先后手提示应如何与 P/N 对齐？

### 2.2 直觉

每次合法走子都在「从大数里剥掉若干倍小数」。当比值 $a/b$ 落在 $\varphi$ 附近的特定整数格点时，当前玩家**无论选哪个 $k$** 都会把对手送进更有利区域——这就是 P 位置。

## 3. 揭示 · Reveal

### 3.1 形式化定义

**定义 1（局面）**：$S = \{(a,b) \in \mathbb{N}^2 \mid a \ge b \ge 0\}$（可玩时 $b>0$）。

**定义 2（合法走子）**：从 $(a,b)$，$a \ge b > 0$，走子 $(a,b) \xrightarrow{k} \text{normalize}(a-kb, b)$，$k \in \{1,\ldots,\lfloor a/b \rfloor\}$；若 $a-kb=0$，当前玩家立即胜。

**定义 3（P / N，本变体）**：

- 清空大堆的走子是**立即胜**（该局面对走子方为 N）。
- 局面 $p$ 为 **N** $\iff$ 存在合法走子到某个 P 局面，或立即胜。
- 局面 $p$ 为 **P** $\iff$ 所有合法走子都到达 N 局面（且不能立即胜）。

> 勿照搬 Nim「终局无棋可走 = P」的叙述：本 Hub 终局是「刚清空大堆的一方已胜」。

### 3.2 φ 败者态定理（实现口径）

设 $\varphi = (1+\sqrt{5})/2$。对 $a > b > 0$：

$$p \text{ 为 P 位置} \iff \lfloor b\varphi \rfloor \ge a \;\wedge\; a < b\varphi$$

**注**：$a=b>0$ 时先手取 $k=1$ 立即胜 → **N 位置**。

与 **取模一步版**（每步变为 $(b, a \bmod b)$）不同，本模块采用 **减法倍数版**（见设计 spec）。部分文献不等式不含等号边界；本仓库以代码 + 暴力互证为准。

### 3.3 与 gcd / 其他博弈的联系

| 对比 | Nim | Wythoff | Euclid's Game（本模块） |
|------|-----|---------|-------------------------|
| 核心不变量 | XOR | Beatty / $\varphi$ | $\varphi$ 区间 + gcd 结构 |
| 典型走法 | 单堆任意取 | 单堆或两堆同数 | 大堆减小堆倍数 |
| P 判定 | nim-sum $=0$ | $a=\lfloor k\varphi\rfloor$ | $\lfloor b\varphi\rfloor\ge a < b\varphi$ |

取模版欧几里得步骤等价于减法版中选择特定 $k$ 序列。Ludus 用 cut-the-knot 常用的 **φ 不等式** 作 O(1) 判定，并用记忆化 minimax 在 $a,b\le 12$ 互证。

## 4. 求解 · Solve

### 4.1 `isPPosition` / `findWinningMove`

```typescript
// packages/games/src/euclids-game/solver.ts
const [larger, smaller] = normalizePiles(a, b);
if (larger === smaller) return false; // N：一步取光
const floorBound = Math.floor(smaller * PHI);
return larger <= floorBound && larger < PHI * smaller;
```

枚举 $k = 1 \ldots \lfloor a/b \rfloor$：立即胜，或落到 P 局面 → 必胜步。

### 4.2 整局序列与选先后手

`solveEuclidsGame` **仿 Nim** 模拟人类与 AI 交替完美对弈，返回完整 `moves`：

- `choosing` 阶段：`playerStarts = !isPPosition(piles)`（N → 人类先；P → AI 先）。
- `visualizationData.playerStarts` 供 Hub 提示高亮与教育面板走子标注。
- 侧边栏「最优解」步数 = 序列中人类步数（`solutionLength`）。

### 4.3 复杂度

| 操作 | 复杂度 |
|------|--------|
| P/N 判定 | $O(1)$ |
| 找一步必胜 | $O(a/b)$ |
| 整局模拟 | $O(\text{深度} \times a/b)$，深度约 $O(\log b)$ |

**AI**：`findWinningMove` 优先；否则均匀随机合法 $k$。

## 5. 出题 · Create

`generateEuclidsGameLevel`（`packages/games/src/euclids-game/generator.ts`）：

1. `resolveSeed(config)` → Mulberry32 PRNG
2. 按 `difficultyRange` 中点采样 $(a,b)$，保证 $a > b \ge 2$
3. `preferPPosition`：高难度偏向 P，低难度偏向 N（最多 24 次重采样）
4. 返回 `phase: 'choosing'` + `initialPiles`；`generatedBy` 为 `n-position-bias` 或 `p-position-bias`（Hub 已 i18n）
