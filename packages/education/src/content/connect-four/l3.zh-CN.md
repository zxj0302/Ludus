# 四子棋 — Minimax / Alpha-Beta 完整推导

## 1. 玩 · Play

Connect Four（四子棋）在 6 行 × 7 列棋盘上，双方轮流将棋子落入某一列，棋子受重力落到该列最底空位。先形成**横、竖、斜**任意方向四连者胜；满盘无四连则为和棋。

本 Hub 版为**人机对战**：开局选先后手，AI 使用深度受限的 Alpha-Beta 搜索（非 Allis 全盘强解库）。

## 2. 思考 · Think

- 若对手下一手即可四连，你必须堵哪一列？能否用一步搜索完成「必胜 / 必堵」检测？
- Minimax 假设双方都最优；若只搜索 6 层，AI 会犯什么典型错误？
- Alpha-Beta 与 Minimax 结果相同，为何节点数能少一个数量级？
- 7×6 标准棋盘已被强解（先手必胜），与 Hub「诚实但有限深度」的 AI 有何差别？

## 3. 揭示 · Reveal

### 3.1 形式化

**状态** $s$：矩阵 $B \in \{0,1,2\}^{6 \times 7}$（0 空，1/2 为双方棋子），外加 `currentPlayer ∈ {0,1}`、`phase ∈ {choosing, playing}`、`playerStarts`（谁先手）。

**行动**：选列 $c \in \{0,\ldots,6\}$ 且该列未满，棋子落至最底空格。

**终局**：某方四连 → 该方胜；满盘无四连 → 和。

### 3.2 Minimax

```text
minimax(s, depth, maximizing):
  if terminal(s) or depth=0: return eval(s)
  if maximizing:
    return max_a minimax(apply(s,a), depth-1, false)
  else:
    return min_a minimax(apply(s,a), depth-1, true)
```

Hub 在 `depth=0` 时用**中心列偏好**作启发式估值；终局用 ±WIN_SCORE。

### 3.3 Alpha-Beta 剪枝

维护窗口 $[\alpha, \beta]$。在 Max 层若估值 $\ge \beta$ 则剪枝；Min 层若估值 $\le \alpha$ 则剪枝。正确性：被剪分支不可能改变根节点最优值。

实现见 `packages/games/src/connect-four/solver.ts`：`findTacticalMove` 在搜索前处理立即获胜 / 必堵。

### 3.4 复杂度

- **博弈复杂度**：PSPACE-complete（一般情形）。
- **搜索树**：分支 $\le 7$，深度 $\le 42$；Alpha-Beta 仍指数级，需深度限制 + 时间预算。
- **强解**：Allis (1988) 证明 7×6 **先手必胜**；完美对局在第 **41** 手终局。详见下文「求解」中的强解与文献。

## 4. 求解 · Solve

### 4.1 求解器管线

1. `findTacticalMove`：O(列数) 检测立即赢棋或挡四。
2. `searchBestMove`：Alpha-Beta，默认 `maxDepth=8`、`timeMs≈4.5s`（Worker 可加深）。
3. `solveConnectFour`：从当前局面模拟双方最优交替落子，输出 `minimax-tree` 轨迹与 `playerStarts`。

AI 落子在 Web Worker 中执行，避免阻塞 UI。

### 4.2 与 UI 的契约

- `GamePlugin.ai.isPlayerVictory`：仅 `winner === 0` 时播放玩家胜利音效。
- 侧边栏「实时分析」在 `phase === choosing` 时不预跑整盘模拟，避免未选先后手就展示虚假走法序列。

### 4.3 7×6 完美对弈与先后手

标准 7×6 在双方皆最优时已**强解**，结论与 [Christophe Steininger c4](https://github.com/ChristopheSteininger/c4) 求解表一致：

| 项目 | 结论 |
|------|------|
| 完美对弈结果 | **先手必胜**（1st） |
| 完美局长度 | 第 **41** 手终局 |

**选先后手：**

- **我先下**（`playerStarts = true`）：完美对弈下你作为先手方，理论上可逼胜。
- **AI 先下**（`playerStarts = false`）：完美对弈下 AI 作为先手方，理论上 AI 可逼胜。

本模块求解器为**深度受限** Alpha-Beta，模拟的是「在搜索深度内双方最优」，**不是** Allis / Tromp / c4 的强解库；侧边栏轨迹与推荐序列仅供教学演示。

## 5. 出题 · Create

`generateConnectFourLevel` **始终**返回：

- 空盘 `6×7`；
- `phase: 'choosing'`（选先后手）；
- 难度分数由 `seed` 映射，写入 `aiMaxDepth`（简单 4 / 中等 6 / 困难 9），**不改变**开局形状。

换关 / 新种子 = 新的空盘实例；对战进度由 `playerStarts` 与落子历史决定。
