# 围堵小偷 — 把逃跑路线堵住

## 1. 玩 · Play

你扮演警察，每回合点击一个空地放置警察。小偷会沿着当前最短路线向边缘出口移动一步；如果它走到出口就逃脱，如果所有路都被堵住，你就围堵成功。

先别急着看算法：观察小偷每次往哪里跑，试着把它的路线越压越窄。

## 2. 思考 · Think

- 小偷为什么总往某个方向跑？
- 堵在小偷旁边一定好吗，还是堵在通道瓶颈处更有效？
- 如果棋盘是不规则形状，哪些格子会成为天然的“卡口”？

## 3. 揭示 · Reveal

把棋盘看成一张图：每个可走格子是一个顶点，相邻格子之间有边，边缘的出口格是目标。小偷当前最直接的目标是找到一条从当前位置到任一出口的最短路。

警察每放一个棋子，就相当于从图中删除一个顶点。删除得好，最短路会变长；删在关键瓶颈上，所有逃脱路径都可能被切断。

这不是在声称当前 AI 做到了完整的追逃博弈最优解。它展示的是一个清晰的图论核心：**BFS 找逃脱路，警察尝试切断路**。

## 4. 求解 · Solve

求解器对当前局面运行 BFS：

```
从小偷位置入队
一层层扩展相邻可通行格
第一次碰到出口 => 得到最短逃脱路径
队列耗尽仍没有出口 => 小偷被围住
```

可视化里高亮的黄色格子就是 BFS 还原出的逃脱路径。点击“求解”时，建议落子会优先堵这条路径上的下一批关键格。

## 5. 出题 · Create

生成器先做一个 7×7、9×9 或 11×11 的不规则轮廓，把轮廓边界标为出口，再在内部挖少量障碍并把小偷放在中心附近。最后用 BFS 验证：初始局面必须至少有一条可逃路径。

难度主要来自三件事：棋盘越大、警察越少、内部障碍越少，小偷可选路径就越多，围堵就越难。
