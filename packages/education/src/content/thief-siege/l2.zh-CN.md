# 围堵小偷 — 把逃跑路线堵住

## 1. 玩 · Play

你扮演警察，每回合点击一个空地放置警察。小偷会向边缘出口移动一步；如果它走到出口就逃脱，如果所有路都被堵住，你就围堵成功。

v1.1 的棋盘更大：简单 11×11，中等 15×15，困难 19×19。先别急着看算法：观察小偷不只是这一步想走哪里，还要猜它下一轮可能改走哪条备用路线。

## 2. 思考 · Think

- 小偷为什么总往某个方向跑？
- 堵在小偷旁边一定好吗，还是堵在通道瓶颈处更有效？
- 如果棋盘是不规则形状，哪些格子会成为天然的“卡口”？
- 现在堵住最短路后，小偷下一回合会不会立刻改走另一条路？

## 3. 揭示 · Reveal

把棋盘看成一张图：每个可走格子是一个顶点，相邻格子之间有边，边缘的出口格是目标。小偷当前最直接的目标是找到一条从当前位置到任一出口的最短路。

警察每放一个棋子，就相当于从图中删除一个顶点。删除得好，最短路会变长；删在关键瓶颈上，所有逃脱路径都可能被切断。

v1.1 进一步把“小偷也会反制”纳入考虑：它会用对抗搜索估计警察未来还能怎么堵，而不是只盯当前最短路。教学可视化仍保留最容易看懂的 BFS 逃脱路径，帮助你理解每次落子正在切断什么。

## 4. 求解 · Solve

求解器先对当前局面运行 BFS：

```text
从小偷位置入队
一层层扩展相邻可通行格
第一次碰到出口 => 得到最短逃脱路径
队列耗尽仍没有出口 => 小偷被围住
```

可视化里高亮的黄色格子就是 BFS 还原出的逃脱路径。点击“求解”时，建议落子来自同一套对抗引擎：小图尽量证明，较大图在时间预算内搜索；如果预算不够，再退回到 BFS 贪心建议。

## 5. 出题 · Create

生成器先做一个 11×11、15×15 或 19×19 的不规则轮廓，把轮廓边界标为出口，再在内部挖少量障碍并把小偷放在中心附近。

简单关会用对抗搜索验证：在正确操作下警察可以赢。中等和困难关更大，生成器使用瓶颈构造加浅层抽检，诚实地说它们是工程保证，不是数学上的全局完美证明。

难度主要来自三件事：棋盘越大、警察越少、内部障碍越少，小偷可选路径就越多，围堵就越难。
