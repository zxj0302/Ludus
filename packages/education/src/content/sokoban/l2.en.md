# Sokoban — How It Works

## 1. Play

> Sokoban was created by Hiroyuki Imabayashi in 1981. "Sokoban" means "warehouse keeper." The player pushes boxes onto goal squares in a warehouse — simple rules, fiendishly difficult puzzles.

## 2. Think

After playing a few levels, ask yourself:

**With only a handful of boxes, why does it take hundreds of moves to solve?** The answer lies in state space explosion — each move creates new branches, and wrong branches only reveal themselves tens of moves later (boxes pushed into deadlock positions).

Consider:
- In an 8×8 warehouse with 4 boxes and 1 player, how many total states are possible? (Answer: ~millions)
- What's the shortest solution for a typical Microban level? How does a computer find it?

## 3. Reveal

### Formal Definition

A Sokoban state consists of:
- **Player position** $(p_r, p_c)$
- **Box set** $\{B_1, B_2, \dots, B_k\}$, each box with coordinates
- **Walls** (impassable)
- **Goals** (positions all boxes must occupy)

**Move**: The player moves one step in one of four directions. If the adjacent cell contains a box and the cell beyond it is empty, the box is pushed.

**Goal**: All boxes on goal squares.

### State Space & Complexity

For a $w \times h$ warehouse with $k$ boxes, the state space upper bound is:

$$|S| \approx wh \times \binom{wh-1}{k}$$

**Complexity class**: **PSPACE-complete** (proved by Culberson, 1997). Sokoban is computationally among the hardest problems requiring exponential space — harder than NP-complete!

### Deadlocks: The Key to Search

Pure BFS fails due to state explosion. The critical optimization is **deadlock detection**:

- **Corner deadlock**: A box stuck in a corner (not on a goal) → permanently trapped
- **Edge deadlock**: A box against a wall, blocked along the wall in both directions → permanently trapped

Pruning deadlocked branches dramatically reduces the search space.

## 4. Solve

### BFS + Deadlock Detection

1. Start from the initial state, explore with BFS layer by layer
2. At each new state, check for deadlocks — skip if detected
3. Use **state hashing** to deduplicate (player coords + sorted box coords)
4. The first state where all boxes are on goals → shortest solution found

BFS guarantees the solution is **optimal** (minimum moves).
